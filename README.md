# CineVault — Movie Discovery App

## About CineVault

CineVault is a movie discovery web application I am developing as part of my web development assignment. I chose the name because I wanted something simple and memorable for a website where people can explore movies.

The aim of the project is to make discovering movies easier through a clear and user-friendly interface. The application focuses on movie discovery rather than video streaming, downloads, payments, or user accounts.

## Features

The application is being developed around the following main purpose:

- **Movie Discovery:** Browse the movies available in the application.
- **Simple Interface:** Navigate the website without unnecessary complications.
- **Movie Information:** Explore the information provided for each movie.

The available features depend on the current implementation of the application.

## Technologies Used

- **React** — for building the user interface.
- **Vite** — for running the development server and building the project.
- **JavaScript** — for the application's functionality.
- **HTML and CSS** — for the structure and styling of the website.
- **Git and GitHub** — for tracking changes and storing the project online.

## How to Run the Project

To run CineVault on your computer, you need to have Node.js and npm installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/rachaelmungufeni-coder/movie-discovery.git
   ```

2. Enter the project folder:

   ```bash
   cd movie-discovery
   ```

3. Install the required packages:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal in your web browser.

## Project Structure

The project is organised into folders and files to make the code easier to manage.

- `src/` — contains the main application code.
- `public/` — stores public assets.
- `index.html` — provides the main HTML page.
- `package.json` — contains project information, dependencies, and scripts.
- `package-lock.json` — records the installed dependency versions.
- `vite.config.js` — contains the Vite configuration.
- `.gitignore` — specifies files Git should ignore.
